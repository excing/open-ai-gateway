Open AI Gateway

一个更顺手的调试首页：左边组织请求，右边统一查看响应和原始结果。请求侧只表达目标 model，由后端决定走哪条 channel。

当前路由分工

  • /api/generate：非流式 AI SDK JSON 子集
  • /api/stream：流式 AI SDK 响应
  • /v1/chat/completions：OpenAI 风格透明代理
